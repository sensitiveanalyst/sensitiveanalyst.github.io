Code

The Python control suite, one page per module.

  • continuity.pyFind continuity breaks in a sampled signal.
  • geometric.pyGeometric control on SO(3) and SE(3) (Lee, Leok, McClamroch, CDC 2010).
  • geometric_pmp.pyGeometric Pontryagin principle for rigid-body attitude (SO(3) x R^3), left-trivialised.
  • kalman.pyKalman filter family: linear (KF), extended (EKF) and unscented (UKF).
  • lyapunov.pyLyapunov tools: stability certificates, LQR and energy-based control.
  • pmp.pyPontryagin minimum principle by indirect shooting (Euclidean state space).
  • smooth.pySmooth replacements for kinks and discontinuities.
  • so3.pyMinimal SO(3) toolkit. Rotations are 3x3 numpy arrays, body-to-inertial.
