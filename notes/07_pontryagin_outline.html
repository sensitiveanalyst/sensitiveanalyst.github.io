07 Pontryagin minimum principle: rough outline

Status. Implemented and tested: pmp.py (indirect shooting, free final time, continuation). Sections marked sketch are not implemented.

1. Problem

min  phi(x(T)) + int_0^T L(x,u) dt     s.t.  x' = f(x,u),  u(t) in U,  x(0) = x0
terminal set S: a point, all of R^n, or {psi(x) = 0};  T fixed or free

2. Necessary conditions (minimum form; Pontryagin's original is a maximum)

H(x,lam,u) = lam0 L + lam . f, lam0 in {0, 1}, (lam0, lam) != 0. 1. x' = dH/dlam, lam' = -dH/dx (u held fixed). 2. u*(t) = argmin_{u in U} H(x*, lam, u) almost everywhere. 3. Transversality: lam(T) - lam0 grad phi annihilates the tangent space of S at x(T). Fixed endpoint: no condition on lam(T). Free endpoint: lam(T) = lam0 grad phi. 4. Autonomous problem: H is constant along the extremal. Free T with phi independent of T: H = 0.

lam0 = 0 (abnormal) means the extremal ignores the cost. The code fixes lam0 = 1 and cannot find abnormal extremals.

3. Pipeline: indirect shooting (what PMPShooting.solve does)

unknowns z = (lam(0), log T)                         # log T keeps T positive
residual(z):
    integrate (x, lam, cost) on tau in [0,1] with time scaled by T, u = argmin H
    r = [ x_i(T) - xT_i            fixed components
          lam_i(T) - dphi/dx_i     free components
          H(T)                     if T is free ]
solve residual(z) = 0 by Newton / hybr with a finite-difference Jacobian

Sensitivity grows like exp(L T) for the Hamiltonian flow. If single shooting stalls, use multiple shooting: unknowns (x_k, lam_k) per segment, continuity as extra residuals, block-sparse Newton. Sketch.

Initialisation pipeline (sketch): direct method first (discretise u, solve the NLP), read the dynamics multipliers as a costate guess (covector mapping principle), then polish with indirect shooting. Pure shooting needs a good lam(0); the code gets one from the double-integrator closed form.

4. Where kinks come from

  • H affine in u (time-optimal, fuel-optimal): u* = -u_max sign(sigma(t)) with switching function sigma = lam . g(x). Jumps in u*. If sigma vanishes on an interval the arc is singular: differentiate sigma until u appears (Kelley, Goh conditions).
  • Fuller's problem (x'' = u, |u| <= 1, cost int x^2) has infinitely many switches in finite time (chattering).
  • H strictly convex in u with a box U: u* = clip(argmin_free), a kink in the map lam -> u*.
  • State constraints c(x) <= 0: the costate can jump at junctions.

All of these make the shooting map non-smooth. Note 09 replaces them with smooth modifiers, and smooth.barrier_* does it inside the cost so the PMP still applies.

5. Second-order conditions and feedback (sketch)

Legendre-Clebsch: H_uu >= 0 along an interior extremal. With A = f_x, B = f_u, Q = H_xx, S = H_ux, R = H_uu the second variation gives

du = -R^-1 (S dx + B^T dlam)
P' = -P(A - B R^-1 S) - (A - B R^-1 S)^T P + P B R^-1 B^T P - (Q - S^T R^-1 S),  P(T) = phi_xx
neighbouring-extremal feedback:  du = -R^-1 (S + B^T P) dx

If P blows up before t = 0 there is a conjugate point and the extremal is not locally optimal beyond it. For linear dynamics with convex cost the extremal is globally optimal. This P(t) is a route from an open-loop PMP solution to a time-varying feedback gain.

6. What the tests check

  • Min-energy double integrator against the closed form u = 6/T^2 - 12 t/T^3.
  • Finite-difference costate rate against the analytic one.
  • Free terminal state against the Riccati solution P(0) = tanh(T + atanh s).
  • Smoothed min-time: 2 <= T_eps <= 2 (1 + eps ln 2), monotone to 2, H = 0, control inside the bound, and one sign change.

7. Open questions

  • Abnormal extremals and rank-deficient endpoints are not handled.
  • Singular arcs need a different u* (from sigma = 0 and its derivatives).
  • No second-order test is run in code yet.
