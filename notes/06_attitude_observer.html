06 Nonlinear complementary attitude observer on SO(3) (sketch)

Goal. A cheap attitude estimate that needs no covariance propagation and has a Lyapunov convergence argument, as a fallback or initialiser for note 01.

Inputs. Gyro w_m = W + b + noise. Body-frame direction measurements v_i (gravity from the accelerometer, magnetic field from the magnetometer) with known inertial references v_i0.

Error signal. For measured directions the rotation mismatch is captured by

w_mes = sum_i k_i * ( v_i x (R_hat^T v_i0) )

which is zero when R_hat maps every reference onto its measurement.

Algorithm

init R_hat = I (or from TRIAD / QUEST on the first sample), b_hat = 0
loop:
  w_mes = sum_i k_i * cross(v_i, R_hat^T v_i0)
  R_hat <- R_hat * exp( (w_m - b_hat + kP * w_mes) dt )     # stays on SO(3)
  b_hat <- b_hat - kI * w_mes * dt

Gains kP (proportional) and kI (bias) trade convergence speed against noise. Both are positive; kI much smaller than kP.

Argument

Take V = sum_i k_i/2 |v_i0 - R_hat v_i|^2 + (1/2 kI) |b_tilde|^2 with b_tilde = b_hat - b. Then V_dot <= 0 under the update above, so the estimate converges almost globally when at least two non-collinear references are available. With a single reference (gravity only) the yaw is unobservable and only the tilt converges.

Tests to write

  • Constant bias on the gyro: b_hat should converge to it while R_hat tracks.
  • Start 170 degrees from the truth: convergence should still occur, slowly.
  • Feed it the attitude from GeometricAttitudeController.simulate with synthetic gyro and accelerometer noise and compare with the EKF.

Open questions

  • Accelerometer corruption during manoeuvres: gate or down-weight k_gravity with the measured specific-force norm.
  • Magnetic disturbance indoors: decide whether to drop the magnetometer term.
