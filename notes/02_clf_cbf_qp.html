02 CLF-CBF quadratic program safety filter (sketch)

Goal. Track a goal with a Lyapunov guarantee while a barrier function keeps the state inside a safe set, solved as a small QP at every step.

Model. Control-affine system x' = f(x) + g(x) u.

  • Control Lyapunov function V(x) >= 0 with inf_u [L_f V + L_g V u] <= -gamma V.
  • Control barrier function h(x), safe set {h >= 0}, requirement L_f h + L_g h u >= -alpha(h).

Algorithm

every control step:
  read x
  solve over (u, delta):
      min   0.5 |u - u_nom|^2  +  p delta^2
      s.t.  L_f V + L_g V u <= -gamma V + delta      # CLF, relaxed by delta
            L_f h + L_g h u >=  -alpha(h)            # CBF, hard constraint
            u_min <= u <= u_max
  apply u

The CLF constraint is relaxed so that safety always wins when the two conflict. lyapunov.py already provides the quadratic V from lqr: V = x^T P x, so L_f V and L_g V are 2 x^T P (A x) and 2 x^T P B.

Pitfalls

  • The QP can be infeasible when the CBF is not valid under the input limits. Check the relative degree and add input-constrained CBF conditions.
  • With relative degree 2 or higher, use a high-order CBF (a chain of class-K functions) or exponential CBF.
  • The relaxation delta means the origin is only attractive when no conflict occurs; there can be undesired equilibria at the safe-set boundary.

Tests to write

  • Single integrator avoiding a disc: check h stays >= 0 under a tight u bound.
  • Report how often the QP is infeasible across random starts.
