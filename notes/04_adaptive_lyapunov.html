04 Adaptive geometric attitude control (sketch)

Goal. Keep tracking when the inertia J is uncertain (payload change).

Idea. Write the control with an estimate J_hat and let a Lyapunov function with a parameter-error term drive the update law. This extends the Lyapunov argument already used in GeometricAttitudeController.

Candidate Lyapunov function.

V = 0.5 eW^T J eW + kR Psi(R, Rd) + c eR . eW + (1/2g) tr(Jt^T Jt)
Jt = J_hat - J        # parameter error, unknown but constant

Algorithm

M      = -kR eR - kW eW + W x J_hat W - J_hat ff        # same form, J_hat in place of J
regress: write  W x J W - J ff = Y(W, ff) theta   with theta = vec(J)   (6 unique entries)
update:  theta_hat_dot = -g Y^T (eW + c eR)             # g is the adaptation gain
project  theta_hat so J_hat stays symmetric positive definite

Expected result: V_dot <= 0, giving eR, eW -> 0 (Barbalat), but J_hat need not converge to J without persistent excitation.

Variants to compare

  • Sliding-mode attitude control with a boundary layer for matched disturbances.
  • Disturbance observer (extended-state Kalman filter from kalman.py) feeding a feedforward term instead of changing the gain structure.

Open questions

  • The cross term c eR . eW needs a bound on c to keep V positive definite; derive the explicit bound before implementing.
  • Robustness to unmodelled torque noise: add sigma modification or a dead zone.
