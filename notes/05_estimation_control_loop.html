05 Estimation to control loop (sketch)

Goal. Wire the estimator into the geometric controller and know what is and is not guaranteed.

sensors (IMU, GNSS) -> invariant EKF (note 01) -> (R_hat, v_hat, p_hat)
                                                      |
reference (xd, vd, ad, b1d) -> QuadrotorSE3Controller (f, M)
                                                      |
                                 safety filter (note 02, optional) -> motors

Algorithm

every IMU tick:      estimator.propagate
every GNSS tick:     estimator.update
every control tick:  (f, M) = controller(x_hat, v_hat, R_hat, W_gyro, reference)
                     (f, M) = safety_filter(f, M)        # optional

What the theory covers

  • Separate stability of the estimator error and the controller error holds for linear systems (separation principle). It does not carry over to nonlinear systems in general.
  • For the group-affine estimator, the error dynamics are autonomous, so an argument can combine the two with a small-gain or cascade bound. Sketch: show the estimator error is bounded and decays; treat it as a vanishing input to the controller's closed loop; check input-to-state stability of the controller with respect to that input.

Tests to build

  • Run the full loop in simulation with sensor noise and compare tracking error using the true state versus the estimate.
  • Sweep the estimator delay; find the delay at which the loop loses stability.
  • Check that the controller gains from QuadrotorSE3Controller still converge with estimated state (gains tuned on true state may not).
