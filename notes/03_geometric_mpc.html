03 Geometric MPC on SO(3) / SE(3) (sketch)

Goal. Receding-horizon control that handles constraints (torque limits, tilt limits) and keeps the state exactly on the manifold.

Discretisation. Lie-group variational integrator:

R_{k+1} = R_k exp(dt W_k)
J W_{k+1} = J W_k + dt (M_k + (J W_k) x W_k)   # simple scheme; a true variational
                                                # integrator solves for W_{k+1}

Algorithm (SQP / iLQR on the manifold)

given current (R0, W0), reference (Rd_k, Wd_k) for k = 0..N
init control sequence M_0..M_{N-1} from GeometricAttitudeController
repeat until converged or iteration budget used:
  roll out states with the integrator
  error      xi_k = log_so3(Rd_k^T R_k) ; w_k = W_k - Wd_k     # tangent-space error
  linearise  (xi, w) dynamics about the rollout: A_k, B_k
  cost       sum xi^T Q xi + w^T Qw w + M^T R M ,  terminal 0.5 xi^T P_N xi
  solve the QP / backward Riccati sweep for dM_k with M bounds
  line search: M_k <- M_k + a dM_k
apply M_0 ; shift the horizon ; warm-start next solve

Use GeometricAttitudeController for the warm start and as the fallback if the solver fails to converge in time.

Terminal ingredients

  • P_N from the LQR Riccati solution of the linearisation at (Rd, Wd).
  • Terminal set: sublevel set of Psi(R, Rd) + 0.5 W^T J W small enough that the geometric controller is feasible within the torque bounds.

Open questions

  • Recursive feasibility is not proven here; it needs the terminal set above.
  • Cost of log_so3 and its Jacobian near an angle of pi.
  • Real-time budget: target a few ms per solve for N around 20.
