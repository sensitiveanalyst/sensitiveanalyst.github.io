01 Invariant EKF on a matrix Lie group (sketch)

Goal. Estimate attitude, velocity and position from IMU plus GNSS without the linearisation inconsistency of a standard EKF on Euler angles.

State. X in SE_2(3): (R, v, p) as one 5x5 matrix. Bias b = (b_g, b_a) is kept as a separate vector appended to the error state.

Why. For group-affine dynamics the log-linear error eta = X_hat^-1 X (or X X_hat^-1) obeys an error equation that does not depend on the trajectory. The Jacobians are then constant along it, which fixes the observability mismatch of the usual EKF.

Algorithm

init  X_hat in SE_2(3), b_hat, P (covariance of xi, with eta = exp(xi))
loop:
  # propagate with IMU (w_m, a_m)
  w = w_m - b_g_hat ; a = a_m - b_a_hat
  R_hat <- R_hat * exp(w dt)
  v_hat <- v_hat + (R_hat a + g) dt
  p_hat <- p_hat + v_hat dt + 0.5 (R_hat a + g) dt^2
  P     <- Phi P Phi^T + Q_d        # Phi from the group-affine error ODE
  # update with GNSS position z
  innov = z - p_hat
  S     = H P H^T + R
  K     = P H^T S^-1
  xi    = K innov
  X_hat <- exp_SE23(xi) * X_hat     # left-invariant update
  b_hat <- b_hat + K_b innov
  P     <- (I - K H) P

Checks to run once implemented

  • NEES over many Monte Carlo runs should sit near the state dimension.
  • Compare against ExtendedKalmanFilter on the same data; the invariant version should keep a consistent covariance for longer runs and larger initial heading error.
  • Yaw is unobservable without a magnetometer or motion: check P grows in that direction when the vehicle is stationary.

Open questions

  • Right versus left invariant form given where the measurement noise lives.
  • Handling GNSS outages: pure propagation drift rate with the chosen Q.
